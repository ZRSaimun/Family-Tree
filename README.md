# Family Heritage Tree

A bilingual (English / বাংলা) family-tree website for the Nayer Chowdhury lineage.

## Included

- English / Bangla language switch
- Clear parent → child connectors
- Generation colour coding
- Spouses and multiple marriages shown inside the family card
- Search across both English and Bangla names
- Expand/collapse family branches
- Main **Mohabbat Ali Munsir** branch shown prominently
- **Abdullah Chamra** branch shown separately in a more compact section
- Unknown names are marked as unrecorded instead of being guessed
- Responsive layout for desktop and mobile
- Print-friendly styling

## Run locally

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

The project is completely static, so it can be published with GitHub Pages from the repository root.
